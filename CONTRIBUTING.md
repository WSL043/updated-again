# Contributing

The easiest contribution is an absurd update reason backed by a real effect.

1. Open an Update Idea issue or edit `content/recipes.json`.
2. Keep recipe payloads data-only and use an existing capability.
3. Run `pnpm check`.
4. Explain what visibly changes and how it rolls back.

For a new capability, follow `docs/ADDING_UPDATE_TYPES.md`. Core changes require all platform checks. Do not include generated installers, local paths, logs, private keys, or third-party assets without redistribution permission.

Project tone is playful; contributor treatment is not. Be direct, kind, and specific.
