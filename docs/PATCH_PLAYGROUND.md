# 补丁混合台

把一次性阅读更新变成「安装 → 拿到材料 → 组合实验 → 留下发现 → 再探索」的小循环。

不是新胶囊能力，不执行内容脚本，不调用生成式 API，也不更改签名账本。材料来自本机已安装 ID 与公开账本的交集；最多缓存七个材料标签，断网时仍须检查当前安装 ID。回滚会移除相应材料的使用资格，但不会删除个人见闻。

## 规则

七类材料，两份可以相同，顺序不影响结果。28 个手写标本家族，每个有摇、晾、叠三种状态，共 84 个可发现状态；不是 84 个独立小游戏。每个组合可复现，重复点击不增加收集数。推荐按钮只挑当前材料能做、且尚未发现的配方。

每日线索采用上海日期，固定 v1 的 84 天轮换池，每轮不重复。日期不依赖最后一次服务器更新、访客时区或已安装材料；前台跨日和恢复焦点时刷新。线索不会过期成绝版奖励，没有连签、体力、随机抽奖或补签费用。缺材料会明确提示，不把当天目标伪装成一定可完成。

## 本地笔记

`updated-again:play-notebook:v1` 只保存稳定配方 ID。JSON 导出/导入最多 32 KB；导入完整校验后取并集，不覆盖已有发现，不信任外来标题、材料、安装 ID 或签名字段。只接受已知版本和配方。笔记不是官方安装证明，也不试图阻止用户编辑自己的进度。

读写失败时继续在当前页面保存内存状态并显著提醒导出；损坏或未来版本的数据不被静默覆盖。跨标签页通过 storage 事件合并；主动清除数据不会被自动复活。材料标签与笔记分开存放，笔记导入不能获得本机未安装的材料。没有服务器上传或用户跟踪。

这是实验笔记备份，不是整个更新宇宙、聊天、安装快照的完整备份。

## 扩展边界

标本在 `src/core/patch-playground.ts` 声明。保留现有配方 ID 与家族顺序，新增家族只追加；增加真正的新材料类型仍须遵循原能力协议和验签要求。扩展数量后同步检查材料缓存上限、笔记文件上限及回归测试。不要偷偷用同一 ID 替换已有发现的含义。

动画只播放一次，尊重 reduced-motion，操作使用原生按钮、select、radio 和 details。移动端使用单列混合台；复制被拒绝时展示可手动复制的文本。

更新账本按 24 条分页，版本放映机选择框也限制在当前页；搜索覆盖完整账本，不裁剪公共历史。首页不再无条件声称「没有断更」。

## 验证

`pnpm check` 包含配方覆盖、交换律、日期边界、84 天轮换、回滚材料检查、损坏/超限/未来格式笔记、存储额度失败、跨标签页合并、分页边界和 React 交互测试。原有版本、协议、验签与构建检查保持不变。
