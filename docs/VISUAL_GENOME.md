# 每日视觉基因

网页每天根据上海日期生成一套可复现的视觉基因。它不是随机拼 CSS：

- 日期决定纸张色、主色、版面比例、几何形状和底纹。
- 当天最新胶囊的公开 seed 只制造小幅突变，不改变阅读顺序。
- 同一个日期和胶囊永远得到同一个结果，截图、复现和回滚都有依据。
- 颜色在生成时检查 WCAG 对比度；版面只从经过响应式验证的三种构图中选择。
- `prefers-reduced-motion` 继续覆盖全部非必要动效。

算法在 `src/core/style-genome.ts`，不依赖远程模型、用户身份或浏览器指纹。以后可以把社区投票、连续更新天数和版本类型作为新基因，但不应让随机数决定导航、正文顺序或交互语义。
