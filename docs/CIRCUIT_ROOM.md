# 补丁接线室

首页的独立本地玩法，无需胶囊、账号或外部服务。点击翻转自己与曼哈顿距离为 1 的邻居，目标是所有接点亮起；3×3、4×4、5×5 分别提供不同规模的搜索空间。

每日题使用上海日期、棋盘尺寸和固定 `circuit-v1` 种子协议生成。自由练习使用浏览器生成的随机种子。生成从全亮局面施加合法操作，因此可解；避免直接随机灯位而产生不可解题目。

提示枚举第一行所有按法，再逐行决定下一行的按法。任何解都对应一种第一行选择，因此最多 32 个候选足以找到最短解。提示显示当前局面的下一步，计分中的理论最少步数对应初始局面。提示使用情况明确标注。

每种尺寸在本机保留最近的每日局和练习局，存储内容只有种子、尺寸、按键历史和提示使用状态。刷新通过重放合法操作恢复；超过 2048 步时提示撤销或重开。无法读取的旧存档不会被自动覆盖；写入失败会告知刷新可能丢失进度。切换到新的上海日期会开始新每日题，不维护远程排行榜，也不上传成绩。

键盘支持方向键选格、空格或回车操作；亮暗有图形和读屏文本双重标记。减少动态效果偏好下仍能正常操作，关闭过渡与庆祝动画。

验证：独立 BFS 穷举全部 512 个 3×3 局面核对最短解，三种尺寸各 180 道生成题验证可解性，并测试撤销、刷新恢复、换日、尺寸切换、提示、通关和存储失败。实现入口：`src/core/circuit.ts` 与 `src/components/CircuitRoom.tsx`。
